What belongs here. Only evidence that is safe in public: behaviour captures, test results, published documentation. Live behaviourการทำงานจริง

The gtag test site and the Google Tag Manager test site each print the consent state on the page, so it can be checked without a debugger. On the gtag site that is the consent commands in the data layer and their position relative to the Google tag. The Google Tag Manager site has none to show — the container applies its default internally — so it reports the state Google’s tags actually read, and each type says whether its value came from the default or from the visitor’s choice.หน้าทดสอบ gtag และหน้าทดสอบ Google Tag Manager ต่างแสดงสถานะความยินยอมไว้บนหน้าเว็บ จึงตรวจได้โดยไม่ต้องใช้ debugger ในหน้า gtag จะแสดงคำสั่ง consent ใน data layer และตำแหน่งของคำสั่งเทียบกับ Google tag ส่วนหน้า Google Tag Manager ไม่มีคำสั่งให้แสดง — container ใช้ค่าเริ่มต้นภายในเอง — จึงแสดงสถานะที่ Google tag อ่านได้จริงแทน และระบุว่าค่าของแต่ละประเภทมาจากค่าเริ่มต้นหรือจากตัวเลือกของผู้เข้าชม
