Consent Mode test siteหน้าทดสอบ Consent Mode

This page exists for the Google CMP Partner Program review. It runs the Netka consent banner over a gtag implementation with Consent Mode v2, and carries nothing else — no analytics beyond the test property, no session recording, no marketing tags.หน้านี้มีไว้สำหรับการพิจารณา Google CMP Partner Program โดยรันแบนเนอร์ขอความยินยอมของ Netka บนเว็บที่ติดตั้งแบบ gtag ร่วมกับ Consent Mode v2 และไม่มีสิ่งอื่นนอกจากนั้น ไม่มี analytics อื่นนอกจาก property ที่ใช้ทดสอบ ไม่มีการบันทึก session และไม่มี marketing tag

What to expectสิ่งที่จะเห็นในหน้านี้

  • The banner appears for every visitor in every region. Netka offers no setting that hides it by country, so there is no location from which it is absent.แบนเนอร์แสดงกับผู้เข้าชมทุกคนในทุกภูมิภาค Netka ไม่มีการตั้งค่าให้ซ่อนแบนเนอร์ตามประเทศ จึงไม่มีพื้นที่ใดที่แบนเนอร์ไม่แสดง
  • Before you choose, the Consent Mode default sets ad_storage, ad_user_data, ad_personalization and analytics_storage to denied, and that command is issued before the Google tag loads.ก่อนที่คุณจะเลือก ค่าเริ่มต้นของ Consent Mode จะตั้ง ad_storage, ad_user_data, ad_personalization และ analytics_storage เป็น denied และส่งคำสั่งนี้ก่อนที่ Google tag จะโหลด
  • Accept grants the purposes described in the banner, Reject keeps every optional purpose denied, and the preference centre allows a per-purpose choice.ยอมรับ จะอนุญาตเฉพาะวัตถุประสงค์ที่อธิบายไว้ในแบนเนอร์ ปฏิเสธ จะคงวัตถุประสงค์ที่ไม่จำเป็นทั้งหมดไว้เป็น denied และศูนย์การตั้งค่าให้เลือกได้ทีละวัตถุประสงค์
  • Consent can be withdrawn at any time through the persistent control the banner leaves on the page.ถอนความยินยอมได้ทุกเมื่อผ่านปุ่มที่แบนเนอร์วางไว้บนหน้าเว็บตลอดเวลา
