Consent Mode test site

This page exists for the Google CMP Partner Program review. It runs the Netka consent banner over a gtag implementation with Consent Mode v2, and carries nothing else — no analytics beyond the test property, no session recording, no marketing tags.

What to expect

  • The banner appears for every visitor in every region. Netka offers no setting that hides it by country, so there is no location from which it is absent.
  • Before you choose, the Consent Mode default sets ad_storage, ad_user_data, ad_personalization and analytics_storage to denied, and that command is issued before the Google tag loads.
  • Accept grants the purposes described in the banner, Reject keeps every optional purpose denied, and the preference centre allows a per-purpose choice.
  • Consent can be withdrawn at any time through the persistent control the banner leaves on the page.

Consent commands observed on this page

Read live from dataLayer by this page, for convenience during the review. It reports what the CMP sent; it does not alter it.
