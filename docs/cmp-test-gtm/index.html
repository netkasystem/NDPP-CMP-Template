Consent Mode test site — Google Tag Manager

This page exists for the Google CMP Partner Program review. It shows the integration Netka recommends to its customers: the consent banner is delivered by the Netka CMP tag inside a Google Tag Manager container, firing on Consent Initialization so the Consent Mode default precedes every other tag.

A gtag version of the same banner is at the gtag test page.

What to expect

  • The page source carries only the container. AutoBlock, the banner and the preference centre all arrive through the Netka CMP tag, which is how customers deploy it.
  • The banner appears for every visitor in every region. Netka offers no setting that hides it by country.
  • The Consent Mode default sets ad_storage, ad_user_data, ad_personalization and analytics_storage to denied before any Google tag in the container fires.
  • Accept grants the purposes described in the banner, Reject keeps every optional purpose denied, and the preference centre allows a per-purpose choice.
  • Region-scoped defaults are configured in the container's Regional consent defaults rows, where Google resolves the visitor's region. This container leaves them empty, matching the worldwide banner.
