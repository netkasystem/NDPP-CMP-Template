Consent Mode test site — Google Tag Managerหน้าทดสอบ Consent Mode — Google Tag Manager

This page exists for the Google CMP Partner Program review. It shows the integration Netka recommends to its customers: the consent banner is delivered by the Netka CMP tag inside a Google Tag Manager container, firing on Consent Initialization so the Consent Mode default precedes every other tag.หน้านี้มีไว้สำหรับการพิจารณา Google CMP Partner Program และแสดงวิธีติดตั้งที่ Netka แนะนำให้ลูกค้าใช้ คือส่งแบนเนอร์ขอความยินยอมผ่าน Netka CMP tag ใน container ของ Google Tag Manager ซึ่งทำงานที่ Consent Initialization เพื่อให้ค่าเริ่มต้นของ Consent Mode มาก่อน tag อื่นทุกตัว

What to expectสิ่งที่จะเห็นในหน้านี้

  • The page source carries only the container. AutoBlock, the banner and the preference centre all arrive through the Netka CMP tag, which is how customers deploy it.ซอร์สของหน้านี้มีเพียง container เท่านั้น AutoBlock แบนเนอร์ และศูนย์การตั้งค่า ทั้งหมดมาผ่าน Netka CMP tag ซึ่งเป็นวิธีเดียวกับที่ลูกค้าติดตั้งจริง
  • The banner appears for every visitor in every region. Netka offers no setting that hides it by country.แบนเนอร์แสดงกับผู้เข้าชมทุกคนในทุกภูมิภาค Netka ไม่มีการตั้งค่าให้ซ่อนแบนเนอร์ตามประเทศ
  • The Consent Mode default sets ad_storage, ad_user_data, ad_personalization and analytics_storage to denied before any Google tag in the container fires.ค่าเริ่มต้นของ Consent Mode ตั้ง ad_storage, ad_user_data, ad_personalization และ analytics_storage เป็น denied ก่อนที่ Google tag ตัวใดใน container จะทำงาน
  • Accept grants the purposes described in the banner, Reject keeps every optional purpose denied, and the preference centre allows a per-purpose choice.ยอมรับ จะอนุญาตเฉพาะวัตถุประสงค์ที่อธิบายไว้ในแบนเนอร์ ปฏิเสธ จะคงวัตถุประสงค์ที่ไม่จำเป็นทั้งหมดไว้เป็น denied และศูนย์การตั้งค่าให้เลือกได้ทีละวัตถุประสงค์
  • Region-scoped defaults are configured in the container's Regional consent defaults rows, where Google resolves the visitor's region. This container leaves them empty, matching the worldwide banner.ค่าเริ่มต้นรายภูมิภาคตั้งได้ในแถว Regional consent defaults ของ container ซึ่ง Google เป็นผู้ระบุภูมิภาคของผู้เข้าชม container นี้เว้นว่างไว้ ให้สอดคล้องกับแบนเนอร์ที่แสดงทั่วโลก
